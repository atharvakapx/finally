<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP client → FastAPI | All `/api/*` requests cross from untrusted internet/loopback into the app; only `/api/health` and the static mount are reachable in Plan 01. |
| Filesystem → app | `load_dotenv()` reads `.env` from CWD; `StaticFiles` reads `backend/static/`. Both are local-trust boundaries. |
| Package registry → app | `uv add python-dotenv` pulls from PyPI. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Information Disclosure | `app/main.py` traceback on import error | mitigate | Lifespan startup uses `logger.info` only; no secrets in env are read in Plan 01, so even an uncaught traceback cannot leak credentials. Phase 5 confirms `.env` is gitignored. |
| T-01-02 | Tampering | `StaticFiles(directory="static")` path traversal | mitigate | FastAPI's `StaticFiles` rejects `..` traversal by default (Starlette behavior). Placeholder directory contains only `index.html`. |
| T-01-03 | Denial of Service | Unbounded request rate against `/api/health` | accept | Single-user demo app, no auth, no rate limiting expected in v1 per PLAN.md scope. |
| T-01-04 | Spoofing | Unauthenticated `/api/health` reveals app presence | accept | Health checks are intentionally public for container orchestrators (PLAN.md §11). No sensitive payload. |
| T-01-SC | Tampering | `uv add python-dotenv` (supply chain) | accept | `python-dotenv` is a well-known, widely-audited PyPI package (millions of weekly downloads, official `theskumar/python-dotenv` repo). RESEARCH.md does not exist for this phase; per planner-source-audit fallback, this is treated as a low-risk legitimacy disposition. No blocking checkpoint needed; if a Package Legitimacy Audit is later added to research, re-evaluate. |
| T-01-05 | Tampering | Static mount registered BEFORE `/api/*` would shadow API | mitigate | Registration order enforced in `main.py` (acceptance criterion checks line ordering); `test_unknown_api_route_returns_404` proves `/api/*` resolves before the catch-all. |
</threat_model>
