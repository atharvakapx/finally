# Walking Skeleton — FinAlly Backend Foundation

The thinnest possible end-to-end stack that proves the entire FinAlly backend
deployment shape. Subsequent phases (2 — Portfolio/Watchlist APIs, 3 — AI Chat,
4 — Frontend, 5 — Docker/E2E) build on these decisions without renegotiating them.

## User Story

**As a** developer cloning FinAlly, **I want to** run `uv run uvicorn app.main:app --port 8000` from `backend/` and have the server boot cleanly with `GET /api/health` returning `{"status": "ok"}`, the SQLite database initialized at `db/finally.db` with all 6 tables seeded, the GBM simulator streaming into the `PriceCache`, and the placeholder page served at `/`, **so that** every later phase plugs into a working stack instead of debugging boot order.

## Architectural Decisions (locked for the project)

| Area | Decision | Source |
|------|----------|--------|
| Framework | FastAPI on Python 3.12 with `@asynccontextmanager` lifespan | CONTEXT D-05 |
| Package manager | `uv` (lockfile + `uv add` / `uv run`) | CLAUDE.md |
| Database | SQLite, single file at `db/finally.db`, idempotent `CREATE TABLE IF NOT EXISTS` + `INSERT OR IGNORE` seed | CONTEXT D-01, D-02, D-07 |
| DB module | `backend/app/db.py` — flat module, schema strings, `init_db()`, `get_db()`, `get_db_immediate()` context managers, no module-level connections | CONTEXT D-03, D-07 |
| DB init timing | At lifespan startup (not per-request) — `init_db()` is idempotent so it runs on every boot | CONTEXT D-01 |
| Shared state | `PriceCache` and `MarketDataSource` stored on `app.state` | CONTEXT D-06 |
| Env loading | `python-dotenv` `load_dotenv()` called at the top of `main.py` before any `os.environ` read | CONTEXT code_context |
| Router layout | Full scaffold in Phase 1: `routers/health.py` (real), `routers/portfolio.py`, `routers/watchlist.py`, `routers/chat.py` (501 stubs) | CONTEXT D-04 |
| Router factory | Routers needing shared state use `create_<x>_router(price_cache, ...)` factories; health is a plain module-level `router` | CONTEXT code_context |
| Static files | `backend/static/` directory; FastAPI `StaticFiles` mount at `/` registered AFTER all `/api/*` routes; placeholder `index.html` until Phase 4 replaces it | CONTEXT D-08, D-09 |
| Market data | Use existing `backend/app/market/` package as-is — `create_market_data_source(cache)` + `create_stream_router(cache)`. No reimplementation. | CLAUDE.md, CONTEXT canonical_refs |
| Logging | `logging.getLogger(__name__)` per module, INFO level, stdout (uvicorn default formatter) | CONTEXT discretion + PLAN.md §11 |
| Money types | SQLite `REAL` (IEEE-754 double) for `cash_balance`, `avg_cost`, `price`, `total_value` | PLAN.md §7 |
| Concurrency primitive | `BEGIN IMMEDIATE` SQLite transactions for write paths; helper `get_db_immediate()` provided in Phase 1 for Phase 2 to consume | DB-05, PLAN.md §8 |
| DB path | `os.environ.get("DB_PATH", "/app/db/finally.db")` — container default, overridable for local dev/tests | PLAN.md §11, code_context |

## Boot Sequence (the contract every phase respects)

1. `load_dotenv()` runs at import time at the top of `app/main.py`.
2. `app = FastAPI(title="FinAlly", lifespan=lifespan)` is constructed.
3. Routes are registered in this order (so `/api/*` always wins over the static mount):
   a. `app.include_router(health.router, prefix="/api")`
   b. Stub routers `portfolio`, `watchlist`, `chat` via `app.include_router(create_<x>_router(...), prefix="/api")`
   c. Stream router via `app.include_router(create_stream_router(cache), prefix="/api")` — registered inside lifespan once `cache` exists
   d. `app.mount("/", StaticFiles(directory="static", html=True), name="static")` — LAST
4. On lifespan startup:
   a. `init_db()` runs (creates `db/finally.db` if missing, applies schema, seeds defaults).
   b. `cache = PriceCache()` constructed.
   c. `source = create_market_data_source(cache)` (simulator unless `MASSIVE_API_KEY` is set).
   d. `await source.start(default_tickers)` for the 10 default tickers from seed_prices.
   e. `app.state.price_cache = cache`, `app.state.market_source = source`.
   f. `yield` (server runs).
5. On lifespan shutdown: `await source.stop()`.

## Local Run Command (must work after Phase 1)

```
cd backend
uv sync --extra dev
uv run uvicorn app.main:app --port 8000 --reload
```

Then:
- `curl -s http://localhost:8000/api/health` → `{"status":"ok"}`
- `curl -s http://localhost:8000/` → returns the placeholder HTML
- `curl -N http://localhost:8000/api/stream/prices` → SSE event stream (events arrive within ~1s)
- `sqlite3 db/finally.db ".tables"` → lists all 6 tables
- `sqlite3 db/finally.db "SELECT id,cash_balance FROM users_profile"` → `default|10000.0`
- `sqlite3 db/finally.db "SELECT ticker FROM watchlist ORDER BY ticker"` → 10 rows (AAPL, AMZN, GOOGL, JPM, META, MSFT, NFLX, NVDA, TSLA, V)

Restarting the server preserves the file — `init_db()` is idempotent and never re-seeds existing rows.

## Test Pyramid (Phase 1 only)

- `tests/test_health.py` — `TestClient` smoke: app boots, `/api/health` returns 200 + `{"status":"ok"}`, placeholder `/` returns 200.
- `tests/test_db.py` — `init_db()` creates all 6 tables, seeds default user + 10 tickers, is idempotent (second call doesn't duplicate seed rows).
- `tests/test_main_integration.py` — full lifespan happy path: market source running after startup, `/api/stream/prices` reachable, all 4 routers registered, stub routers return 501.

All Phase 1 tests use a temp DB via env var `DB_PATH=<tmp>/finally.db` set in a pytest fixture so tests never touch `db/finally.db`.

## What Phase 1 Does NOT Do

- No `/api/portfolio*`, `/api/watchlist*`, `/api/chat` implementation — stubs return `{"error":"not_implemented","message":"Coming in Phase N"}` with status 501.
- No portfolio snapshot cadence task (Phase 2).
- No LLM client / LiteLLM wiring (Phase 3).
- No Dockerfile, no start/stop scripts, no `.env.example` (Phase 5).
- No `db/finally.db` committed — `.gitkeep` keeps the directory; gitignore for the DB file is Phase 5's responsibility.
