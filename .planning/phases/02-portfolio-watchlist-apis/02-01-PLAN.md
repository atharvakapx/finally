<objective>
Deliver the core trading capability: a user can read their portfolio (cash, positions with live P&L, total value) and execute market buys/sells against live cache prices, with cash and positions updating consistently and concurrent buys protected from double-spend.

Purpose: This is the central user-observable capability of Phase 2 — money moves correctly and safely. Phase 3's LLM auto-execution (CHAT-03) will call `execute_trade(...)` directly, so the trade logic must live in a pure-Python service function, not inside the HTTP handler.

</objective>

**As a** trader (or a future LLM caller), **I want to** buy and sell shares against live prices and see my portfolio with live P&L, **so that** my cash and positions stay correct and I can never accidentally double-spend.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP client → /api/portfolio/trade | Untrusted JSON body (ticker, side, quantity) crosses into a money-mutating write path |
| Trade handler → SQLite write | Concurrent writers contend for cash/position rows |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | execute_trade SQL (ticker/side/quantity) | mitigate | Parameterized `?` SQL only; never interpolate user input into query strings |
| T-02-02 | Tampering / EoP | concurrent buys double-spending cash | mitigate | Read-validate-write entirely inside one `get_db_immediate()` (`BEGIN IMMEDIATE`) block; concurrency test asserts cash never < 0 |
| T-02-03 | Tampering | negative/non-numeric quantity to mint shares/cash | mitigate | `invalid_quantity` guard (`quantity > 0` and numeric) before any write |
| T-02-04 | Denial of Service | trade arithmetic on missing cache price (None*qty → 500) | mitigate | Check `price is None` before arithmetic; return documented `503 market_data_unavailable` |
| T-02-05 | Information Disclosure | error messages leak internals | accept | Messages contain only the caller's own dollar/share amounts; generic 500 elsewhere; no stack traces |
| T-02-SC | Tampering | npm/pip/cargo installs | mitigate | No new packages introduced this plan (RESEARCH Package Legitimacy Audit: zero new deps); nothing to install |
