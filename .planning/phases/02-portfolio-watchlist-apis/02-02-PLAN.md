<objective>
Deliver full watchlist management: a user can view their watchlist with live prices and session Δ%, add new tickers (validated, capped, streamed immediately), and remove tickers (blocked while a position is held).

Purpose: The watchlist defines the active ticker set the market source streams. Phase 3's LLM (CHAT-04) and Phase 4's UI both call these endpoints, so add/remove logic lives in a pure-Python service. Session Δ% baseline is process-local in-memory state (first observed price), per PLAN.md §6 — never persisted, never tick-over-tick.
Output: `backend/app/services/watchlist.py`, a fully-implemented `backend/app/routers/watchlist.py`, an additive `app.state.session_baselines` map wired in `backend/app/main.py`, and `backend/tests/test_watchlist.py`.
</objective>

## Phase Goal

**As a** trader (or a future LLM caller), **I want to** view, add, and remove watchlist tickers with live prices and session Δ%, **so that** I control which symbols stream and I can't accidentally drop a ticker I still hold.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP client → POST /api/watchlist | Untrusted `ticker` string crosses into validation + DB write + market source mutation |
| HTTP client → DELETE /api/watchlist/{ticker} | Untrusted path param; must not drop a held ticker (silent P&L freeze) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-W1 | Tampering | watchlist SQL (ticker param) | mitigate | Parameterized `?` SQL only; ticker upper-cased + regex-validated before write |
| T-02-W2 | Tampering | invalid ticker format | mitigate | `^[A-Z]{1,5}$` fullmatch → `invalid_ticker` before any write |
| T-02-W3 | Denial of Service | unbounded watchlist growth (cache/SSE payload) | mitigate | 50-ticker cap → `watchlist_full` (WATCH-04) |
| T-02-W4 | Tampering | removing a held ticker freezes P&L silently | mitigate | `ticker_held` guard queries positions.quantity > 0 before delete (WATCH-03) |
| T-02-W5 | Information Disclosure | error messages | accept | Messages contain only generic validation text; no internals |
| T-02-SC | Tampering | npm/pip/cargo installs | mitigate | No new packages this plan (RESEARCH audit: zero new deps) |
</threat_model>
