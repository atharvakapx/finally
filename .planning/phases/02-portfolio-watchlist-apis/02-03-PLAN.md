The cleanest, lowest-risk reconciliation with the "market package is complete — do not reimplement" rule is a ~6-line ADDITIVE counter hook in `_generate_events` (increment on connect, decrement in `finally`). This plan must NOT rewrite stream.py — only add the counter calls.
Output: `backend/app/services/snapshots.py` (ClientCounter + record_snapshot + snapshot_loop), additive edits to `backend/app/main.py` (counter + cadence task) and `backend/app/market/stream.py` (counter hook), the `record_snapshot` call wired into the trade route in `backend/app/routers/portfolio.py`, the real `/history` route, and `backend/tests/test_snapshots.py`.
</objective>
