### Task 2 — Implement services/chat.py

Create `backend/app/services/chat.py` with these functions:

**`is_mock_mode() -> bool`**
Returns True if `OPENAI_API_KEY` env var is absent/empty OR `LLM_MOCK` env var is `"true"` (case-insensitive).

**`build_chat_context(price_cache: PriceCache) -> dict`**
Reads from DB and cache:
- User cash balance from `users_profile`
- All positions with quantity, avg_cost, current_price from cache, unrealized_pnl, pct_change
- All watchlist items with current_price from cache, session_change_pct from app state (pass as param)
- Last 20 messages from `chat_messages` (oldest first) as `[{role, content}]`
- Computes total_portfolio_value = cash + Σ(qty × price)
Returns dict with: cash, positions, watchlist, total_portfolio_value, recent_messages

**`call_llm(user_message: str, context: dict) -> dict`**
If `is_mock_mode()`: return deterministic mock response:
```python
{
    "message": "I'm FinAlly, your AI trading assistant. How can I help you today?",
    "trades": [],
    "watchlist_changes": []
}
```
Otherwise, call LiteLLM:
```python
import litellm
response = litellm.completion(
    model="gpt-4.1-mini",
    messages=[
        {"role": "system", "content": SYSTEM_PROMPT},
        *[{"role": m["role"], "content": m["content"]} for m in context["recent_messages"]],
        {"role": "user", "content": user_message}
    ],
    response_format={"type": "json_object"},
)
```
Parse `response.choices[0].message.content` as JSON. If parsing fails, return `{"message": content_string, "trades": [], "watchlist_changes": []}`.

**System prompt** (module constant `SYSTEM_PROMPT`):
```
You are FinAlly, an AI trading assistant for a simulated portfolio. 
You have access to the user's current portfolio state below.

Portfolio Context:
{context_json}

Instructions:
- Respond with valid JSON matching: {"message": "...", "trades": [...], "watchlist_changes": [...]}
- trades: [{"ticker": "AAPL", "side": "buy"|"sell", "quantity": <number>}]
- watchlist_changes: [{"ticker": "AAPL", "action": "add"|"remove"}]
- For dollar amounts ("buy $500 of NVDA"), convert to shares using the live price in context
- Be concise and data-driven. Always respond with valid JSON.
```
Inject context as `context_json = json.dumps({k: v for k, v in context.items() if k != "recent_messages"}, indent=2)`.

**`execute_chat_actions(price_cache, market_source, trades, watchlist_changes) -> list[str]`**
Execute trades via `execute_trade(price_cache, ticker, side, qty)` — collect errors, don't raise.
Execute watchlist changes via `add_ticker_to_watchlist` / `remove_ticker_from_watchlist`.
Return list of action result strings for inclusion in response.

**`save_messages(user_message: str, response: dict, actions: list[str]) -> None`**
Insert two rows into `chat_messages`:
1. `{role: "user", content: user_message, actions: null}`
2. `{role: "assistant", content: response["message"], actions: json.dumps({"trades": response.get("trades",[]), "watchlist_changes": response.get("watchlist_changes",[]), "results": actions})}`

### Task 3 — Implement routers/chat.py (replace 501 stub)

Replace the existing stub with a real implementation:

```python
def create_chat_router(price_cache: PriceCache) -> APIRouter:
    router = APIRouter(prefix="/chat", tags=["chat"])

    @router.post("")
    async def send_message(request: Request) -> JSONResponse:
        try:
            body = await request.json()
        except Exception:
            return JSONResponse({"error": "invalid_request", "message": "Body must be valid JSON"}, status_code=400)
        
        user_message = (body.get("message") or "").strip()
        if not user_message:
            return JSONResponse({"error": "invalid_request", "message": "message field required"}, status_code=400)
        
        context = build_chat_context(
            request.app.state.price_cache,
            request.app.state.session_baselines,
        )
        response = call_llm(user_message, context)
        actions = await execute_chat_actions(
            request.app.state.price_cache,
            request.app.state.market_source,
            response.get("trades", []),
            response.get("watchlist_changes", []),
        )
        save_messages(user_message, response, actions)
        return JSONResponse({
            "message": response.get("message", ""),
            "trades": response.get("trades", []),
            "watchlist_changes": response.get("watchlist_changes", []),
            "actions": actions,
        }, status_code=200)

    return router
```

Update `backend/app/main.py`: change `create_chat_router()` to `create_chat_router(price_cache)`.
