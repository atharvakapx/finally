## Tasks

### Task 1 — MainChart (price history from SSE buffer)

Create `frontend/app/components/MainChart.tsx`:
- Receives `ticker: string` and `priceHistory: number[]` (accumulated from SSE in page.tsx)
- Uses lightweight-charts `createChart` to render a line series
- Chart background matches dark theme: `#0d1117`, grid lines `#30363d`, text `#8b949e`
- Shows last N prices from the ring buffer as a line chart
- Renders "Select a ticker" placeholder when no ticker selected

**Commit:** `feat(04-02): MainChart — lightweight-charts price history for selected ticker`

### Task 2 — Portfolio components

Create `frontend/app/components/PortfolioHeatmap.tsx`:
- Fetches `GET /api/portfolio` on mount and polls every 3s
- Renders positions as a CSS flexbox treemap: each box sized by `(position_value / total_portfolio_value) * 100%`
- Color: `hsl(${pnl_pct > 0 ? 120 : 0}, ${Math.min(Math.abs(pnl_pct)*10, 80)}%, 30%)` — saturated green/red
- Shows ticker + P&L % in center of each box
- Empty state: "No positions yet"

Create `frontend/app/components/PnLChart.tsx`:
- Fetches `GET /api/portfolio/history` on mount and polls every 30s
- Renders total_value over time using lightweight-charts AreaSeries
- X-axis: recorded_at timestamps; Y-axis: total_value

Create `frontend/app/components/PositionsTable.tsx`:
- Fetches `GET /api/portfolio` and re-fetches every 3s
- Table columns: Ticker | Qty | Avg Cost | Current Price | Unrealized P&L | Change %
- P&L column colored green/red
- Empty state: "No positions"

**Commit:** `feat(04-02): PortfolioHeatmap, PnLChart, PositionsTable`

### Task 3 — TradeBar

Create `frontend/app/components/TradeBar.tsx`:
- Controlled inputs: ticker (text, uppercase), quantity (number)
- Buy button: POST /api/portfolio/trade `{ticker, side: "buy", quantity}`
- Sell button: POST /api/portfolio/trade `{ticker, side: "sell", quantity}`
- Shows last trade result inline (success: "Bought 10 AAPL @ $192.43", error: error message)
- Clears quantity on success; disables buttons while request in flight
- On success, fire a custom event `portfolio-updated` so PortfolioHeatmap/PositionsTable refresh

**Commit:** `feat(04-02): TradeBar — buy/sell form wired to POST /api/portfolio/trade`

### Task 4 — ChatPanel

Create `frontend/app/components/ChatPanel.tsx`:
- State: `messages: {role, content, actions?}[]`, `input: string`, `loading: boolean`
- Fetches message history from `GET /api/chat` on mount (if endpoint returns history) — or starts empty
- Submit: POST /api/chat `{message: input}`, append user + assistant messages to state
- Shows loading spinner while waiting
- For each assistant message with trades/watchlist_changes: show inline confirmation badge
  e.g. "Executed: BUY 10 AAPL @ $192.43"
- Collapsible panel: toggle button in top-right corner
- Auto-scrolls to bottom on new message

**Commit:** `feat(04-02): ChatPanel — AI chat with loading indicator and inline trade confirmations`
