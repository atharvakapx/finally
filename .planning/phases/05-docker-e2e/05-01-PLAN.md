### Task 1 — Multi-stage Dockerfile

Create `Dockerfile` at repo root:

```dockerfile
# Stage 1: Build Next.js static export
FROM node:20-slim AS frontend-builder
WORKDIR /app/frontend
COPY frontend/package*.json ./
RUN npm ci
COPY frontend/ ./
RUN npm run build

# Stage 2: Python backend + static frontend
FROM python:3.12-slim AS app

# Install uv
COPY --from=ghcr.io/astral-sh/uv:latest /uv /usr/local/bin/uv

WORKDIR /app/backend
COPY backend/pyproject.toml backend/uv.lock ./
RUN uv sync --frozen --no-dev

COPY backend/ ./

# Copy frontend static export
COPY --from=frontend-builder /app/frontend/out /app/static

WORKDIR /app
COPY --from=frontend-builder /app/frontend/out /app/backend/static

EXPOSE 8000

CMD ["uv", "run", "--project", "/app/backend", "uvicorn", "app.main:app", "--host", "0.0.0.0", "--port", "8000"]
```

Update `backend/app/main.py` to serve static files. Find the existing StaticFiles mount (should already serve frontend/placeholder) and update the path to `/app/backend/static` when running in Docker, falling back to a local path for dev:

```python
import os
STATIC_DIR = os.environ.get("STATIC_DIR", str(Path(__file__).parent.parent / "static"))
# Mount static files (frontend export) — serve at root
if Path(STATIC_DIR).exists():
    app.mount("/", StaticFiles(directory=STATIC_DIR, html=True), name="static")
```

Set `STATIC_DIR=/app/backend/static` in the Dockerfile CMD or as ENV.

### Task 2 — Start/stop scripts

Create `scripts/start_mac.sh`:
```bash
#!/usr/bin/env bash
set -e
IMAGE=finally
CONTAINER=finally

# Build if image doesn't exist or --build flag passed
if [[ "$1" == "--build" ]] || ! docker image inspect "$IMAGE" &>/dev/null; then
  echo "Building $IMAGE image..."
  docker build -t "$IMAGE" "$(dirname "$0")/.."
fi

# Stop existing container if running
docker rm -f "$CONTAINER" 2>/dev/null || true

# Run
docker run -d \
  --name "$CONTAINER" \
  -v "$PWD/db:/app/db" \
  -p 8000:8000 \
  --env-file .env \
  "$IMAGE"

echo "FinAlly running at http://localhost:8000"
```

Create `scripts/stop_mac.sh`:
```bash
#!/usr/bin/env bash
docker rm -f finally 2>/dev/null || true
echo "FinAlly stopped."
```

Create `scripts/start_windows.ps1`:
```powershell
param([switch]$Build)
$Image = "finally"; $Container = "finally"
if ($Build -or !(docker image inspect $Image 2>$null)) {
    Write-Host "Building $Image image..."
    docker build -t $Image "$PSScriptRoot\.."
}
docker rm -f $Container 2>$null
docker run -d --name $Container -v "${PWD}/db:/app/db" -p 8000:8000 --env-file .env $Image
Write-Host "FinAlly running at http://localhost:8000"
```

Create `scripts/stop_windows.ps1`:
```powershell
docker rm -f finally 2>$null
Write-Host "FinAlly stopped."
```

Make shell scripts executable: `chmod +x scripts/start_mac.sh scripts/stop_mac.sh`
